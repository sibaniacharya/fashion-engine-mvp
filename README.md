# Fashion Engine MVP

An AI Wishlist Decision Assistant built for a seamless user experience. This MVP project features a multi-screen setup (5 screens) that is Netlify-ready for easy deployment.

## Features & Navigation

- **Assistant:** AI-driven interaction to help the user make decisions on their wishlist items.
- **Compare:** Compare options between items.
- **Product:** Individual product detail screens.
- **Result:** Decision results based on chosen actions.

### Fixed Actions

- **Assistant actions:** `Compare Options -> /compare/`, `Make Decision -> /result/?choice=current`.
- **Compare actions:** `Choose Saved Product / Choose Alternative / Keep in Wishlist -> Decision Result`.

## Deployment

This project includes a `netlify.toml` and `_redirects` for drop-in static deployment to Netlify.
